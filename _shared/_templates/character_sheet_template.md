# 角色卡模板

> 复制到 `works/<作品>/02_characters/<角色名>/`。同一角色**不同阶段各建一张卡**（少年/中年、落魄/显赫…）。

```
【角色卡】
姓名　　　：
所处阶段　：□ 早期　□ 中期　□ 后期
一句话形象：
──────────────────────────────
年龄气质　：
身形　　　：
面部特征　：（眉眼、脸型、有无胡须、疤痕）
发型发饰　：★ 必须固定（束发/散发/方巾/乌纱/斗笠…）
上衣　　　：形制 ______　颜色 ______　材质 ______
下装/腰带　：
外披　　　：
足履　　　：
兵器/持物　：形制 ______　佩戴位置 ______
标志物　　：★ 给一个记忆点（玉佩、酒器、旧伤、随身书卷…）
──────────────────────────────
固定提示词（英文，每个镜头复制粘贴）：


负面提示词：
  modern clothing, japanese kimono, chinese opera makeup,
  extra fingers, deformed hands, blurry face, watermark, text
──────────────────────────────
参考图：□ 正面　□ 侧面　□ 半身　□ 全身　（存同目录）
可用种子号：
备注（易崩点）：
```

**一致性要点**：跨镜头不变脸靠**锁定参考图 + 图生视频 + 固定提示词**，不是靠种子。种子只在同工具同提示词下重现单次生成。多角色要「一眼可辨」——分配互不重叠的主色 + 剪影轮廓。
