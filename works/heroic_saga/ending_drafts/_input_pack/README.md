# 续写输入包（共享 · 只进不出）

> 三个模型**并行独立续写**《英雄志》结局。本目录是三方共享的**唯一输入来源**，由协调者维护。
> **铁的规则：三个模型只能读本目录，绝不互相读对方草稿。**

## 目录约定

```
_input_pack/
├── README.md          本文件
├── canon_facts.md     已出版卷（vol00-22）的事实锚点摘要（不复制原文大段）
├── ending_titles.md   未出版结局卷章目（23-26）
└── task_brief.md      续写任务书（三份草稿各自遵守的规矩）
```

## 隔离规则

- 三个模型各写各的、分别落盘：`draft_A/`、`draft_B/`、`draft_C/`。
- **任何草稿不读另一份草稿**；协调者合并时才看。
- 草稿目录不提交进 git（个人创作，避免污染主库）。
- 输入包本身是共享事实，可提交（不含原著大段原文，版权安全）。
