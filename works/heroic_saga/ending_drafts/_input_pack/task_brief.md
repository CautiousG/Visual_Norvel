# 续写任务书 · 《英雄志》结局续写（第一阶段：概述）

> 给**续写模型**的指导书。请务必先读本文件 + 同目录 `canon_facts.md` + `ending_titles.md`，然后按分配开始写。

## 当前阶段：只写概述（每卷+每章），不写正文

小说《英雄志》已出版到 vol22《八王世子》，结局（vol23-26）正文**从未出版**，只有公开标题。请你为 **vol23–26 全部四卷** 创作**概述/大纲**——即：每卷一段话总纲 + 每章一段话剧情概要（说明这一章发生什么、登场人物、气氛）。**先不要写完整正文**，概述即可，用于三方比对立意与结构。

## 铁的规则（防相互影响）

1. **只读 `_input_pack/`（本目录）这三个文件**：README / canon_facts / ending_titles / task_brief。除此之外**不要读任何其他文件**。
2. **绝不读别的草稿**：`draft_A/`、`draft_B/`、`draft_C/` 中只有你被分配的那一个目录是你的。其他两个目录里的内容**不得查看**——那是另两个模型在写，各自保密。
3. **只写进你自己的目录**：按分工落盘到你的 `draft_X/`。
4. 你的续写是**独立创作**，不需要与其他模型的草稿衔接。你可以自由决定人物走向、伏笔回收方式、悬念如何落地（只要不与 `canon_facts` 已出版内容矛盾、不偏离四卷章名暗示）。
5. **不复制大段原文**：`canon_facts.md` 是摘要。概述要用你自己的话写，不要整段照抄已出版卷的句子。

## 分工与分配

第一阶段：**三个模型都写 vol23–26 全部四卷的概述**，各自独立、互不参考。

| 模型 | 落盘目录 |
|------|---------|
| 模型 A | `draft_A/outline.md` |
| 模型 B | `draft_B/outline.md` |
| 模型 C | `draft_C/outline.md` |

> 每个模型都写一份完整概述（覆盖 23/24/25/26 四卷）。三份概述将来由协调者拿去做**横向比对**——比的是立意、收尾方向、悬念回收方式，不改写任何一方。


## 时间与篇幅

- 每卷总纲 2-4 句。
- 每章概述 2-4 句即可，不用展开到对白。
- 总篇幅：四卷概述总共可到 2000-4000 字，自由发挥。
