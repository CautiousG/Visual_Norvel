# 英雄志 · 全书主线综述

## 定位（时代 / 气质 / 篇幅）

- **时代**：架空王朝，横跨**武英、景泰、正统**三朝。总起于武英十五年御驾亲征惨败、构陷武德侯（大都督）秦霸先满门（vol00 楔子）；主线集中于景泰、正统年间，直至正统十一年正月十六怒苍大军兵临北京（vol20–vol22，vol21:537 原文）。（各朝纪年据梗概，是否对应真实史朝待核。）
- **气质**：悲剧底色的家国武侠。以「忠而见诛」「英雄被诬为反贼」为骨，反复叩问天命与人事、正邪之辨、乱世中「正道」何在。基调沉郁悲愤，庙堂权谋与官场黑暗贯穿始终，而以「为天地立心、为生民立命」的儒侠理想相抗。武功是手段，抉择与命运感才是主线。
- **篇幅**：超长篇、四线并进。现有梗概数据覆盖楔子（vol00）至第二十二卷，共 23 卷。（是否完结、总字数待核。）

## 四条人物主线

- **[[卢云]]**：山东潍县落第秀才，志在「为天地立心、为生民立命」。历牢狱诬陷、扬州初恋顾倩兮，因义救[[伍定远]]卷入羊皮案，被[[秦仲海]]识为卧龙投军；护送银川公主西行、高中一甲状元，又在柳门血案中沦为送礼帮凶、抱遗孤投怒苍，信念崩解。被幽禁瀑布十年后隔世归来，悟出「正十七边形／以圆应世」武学与宽恕之道，被众人推为刺杀[[杨肃观]]的「最后一卦」人选。全书的良知与「正道」化身。

- **[[秦仲海]]**：征西大都督、怒苍山匪酋秦霸先的遗孤（本名秦文远），「火贪一刀」豪迈成名，慧眼识卢云为卧龙。从柳门大将坠为反贼遗孤，遭江充刖足穿骨、废去武功，绝境徒手登珠母朗玛峰「问天」重生，武功不复反增；重建怒苍、燃狼烟反出朝廷成「怒王」。历舍情、弃兄、断师三关，开寨跪降一夜白头，终率千万「饿鬼」兵临北京，与疑为其子的阿秀在地窖相认却不点破。悲剧英雄——「宁为战国魂，莫为太平奴」。

- **[[伍定远]]**：西凉名捕，暗器飞天银梭成名，四主角中最早登场。由名捕坠为亡命逃犯，献羊皮得柳昂天保荐；中毒被掳后误打误撞练成天山绝学「披罗紫气」，成「一代真龙」，官至五军大都督。心中有一把尺——「不容世间有人斗胆灭人满门」，为燕陵镖局八十三条冤魂向[[卓凌昭]]复仇。终成正统军柱石，被逼当驱赶灾民的「屠夫」，却拒绝让部下屠杀百姓。

- **[[杨肃观]]**：兵部职方司郎中、少林天绝僧关门弟子（灵吾玄志）。风流郎中的表象下是全书真正的幕后布局者——「修罗王」「大掌柜」、镇国铁卫最高首领。放羊皮秘辛、害刘敬、借柳昂天扳倒对手、削爵诈死取正统玉玺，图以「真龙」复辟武英王朝、建「太平佛国」。以「政道」之名行统御，无爱无恨如行尸的终极权谋者。

## 全书脉络（时间线）

1. **楔子（vol00）**：武英十五年构陷秦霸先满门，方子敬救出幼弟受托孤；秦霸先沙地写下「戊辰岁终，龙皇动世，天机犹真，神鬼自在」十六字天机，背「反贼」之名走上最后一战。四主角均未以本名登场。
2. **西凉风暴（vol01）**：伍定远查燕陵镖局灭门案，发现昆仑山所图为玉带藏图，反被诬为凶手，由名捕坠为逃犯；进京求见御史却见其已被抄家，束手待缚。
3. **乱世文章（vol02）**：卢云入狱蒙冤、南逃扬州为顾府书僮，与顾倩兮相恋，逃犯身份败露被逐，挑担卖面浪迹江湖。
4. **京城之会（vol03）**：卖面郎卢云救伍定远卷入羊皮案，被杨肃观所救；伍定远献羊皮平反；卢云被秦仲海识为卧龙。**四大主角首次同框**。羊皮秘辛渐揭：先帝被弑、江充卖国。
5. **神鬼亭外（vol04）**：杨肃观西行查案，除夕神鬼亭之会，戊辰岁终子时天摇地动，伍定远坠石窟遭怪物咬伤，「龙皇动世」揭开一角。
6. **西出阳关（vol05）**：卢云、秦仲海护送银川公主和亲，卢云与公主共历生死情愫暗生终以大义诀别；秦仲海遇石刚，飞虎刺青埋下身世之谜。
7. **一代真龙（vol06）**：伍定远天山神机洞探险，破解机关练成「披罗紫气」成「一代真龙」，发现「驾崩」的武英皇帝之秘。
8. **天下第一（第七卷）**：宁不凡封剑，击溃卓凌昭坐实天下第一；吴安正为伍、卢、杨相面，埋真龙、文曲、寒宫命格伏笔。
9. **金榜题名（vol08）**：柳昂天焚羊皮弃守复辟；卢云高中状元、与顾倩兮终成眷侣。
10. **神剑擒龙（vol09）**：卓凌昭得神剑「擒龙」；伍定远为复仇重伤坠江；秦仲海得知自己是秦霸先遗孤。
11. **忠义孤臣（vol10）**：刘敬政变败露，秦仲海认父、被江充废去武功；卢云、伍定远救出秦仲海；卓凌昭跳崖自尽。
12. **重建怒苍（vol11）**：秦仲海绝境登顶重生，扬刀立誓，燃狼烟号召旧部反出朝廷。
13. **十面埋伏（vol12）**：怒苍反败为胜重创江翼；柳昂天荐杨肃观代理征北大都督，杨被引上「修罗王」血路。
14. **海上孤鸿（vol13）**：怒苍兵临少室山与少林三战；秦仲海坠达摩院密洞，直面欲复辟武英皇帝的黑衣大仇人。
15. **正统王朝（vol14）**：天绝被杀，杨肃观（修罗王）浮出为二十年死局布局者；柳昂天玉石俱焚，卢云抱遗孤带玉玺投怒苍。
16. **镇国铁卫（vol15）**：杨肃观率三十九死士自号「镇国铁卫」；秦仲海壮士断腕开寨跪降、一夜白头；卢云护婴流亡、孤岛悟宽恕之道。（末尾十年后「魁星战五关」新一代）
17. **业火魔刀（vol16）**：业火魔刀消息走漏；被幽禁十年的卢云自贵州白水瀑归来重返人间。
18. **天之正道（第十七卷）**：襄阳大战为秦仲海弃车保帅之局；杨肃观自曝神剑主人身份迎回银川公主；卢云被带回北京、护国寺法会心碎。
19. **吾国吾民（vol18）**：小人物王一通的绝望；卢云拒馈赠、重逢顾倩兮；琼府揭镇国铁卫内情。
20. **王者之上（第十九卷）**：霸州百万饿鬼与勤王军对峙，伍定远孤身托墙力竭；唐王追查杨远身世；万福楼「开锣」。
21. **保卫京城（vol20）**：万福楼一夜血战，大掌柜以「天诀」夺神剑魔刀；诸秘辛集中揭破指向杨肃观；百万饿鬼兵临城下，伍定远高呼「保卫京城」。
22. **兵临城下（vol21）**：秦仲海率饿鬼围北京；卢云暗持阿修罗王令潜入杨府；阿秀误入地窖与秦仲海「铁脚大叔」相认（疑似父子而未点破，身世谜留白）；红螺寺行宫冷血算计屠民。
23. **八王世子（第二十二卷）**：红螺寺立储大会多路人物汇聚；揭「皇后娘娘的儿子不姓朱」等核心大秘密；皇帝抛出「万方有罪，罪在朕躬」诛心之问，大变将至。

## 势力格局

- **朝廷 / 庙堂**：正统皇帝居中；两大权臣殊死缠斗——**江充**（外朝奸臣，卖国改界的景泰始作俑者，卷末从容赴死）与**刘敬**（东厂大太监，谋政变败露焚府逃亡）。**柳昂天**（善穆侯征北都督，「柳门」之主）为忠臣代表，义子[[杨肃观]]、四将（观海云远，卢伍等分属）在其麾下；柳门最终玉石俱焚。
- **镇国铁卫 / 太平佛国**：[[杨肃观]]（修罗王／大掌柜／灵吾玄志）暗中经营的终极势力，三十九名烙印孤鸿死士，图复辟武英王朝、建太平佛国。（琼武川暗为镇国铁卫三当家。）
- **怒苍山（反军）**：秦霸先旧部，二十年后由[[秦仲海]]重建。五虎上将李铁衫、石刚（煞金）、陆孤瞻等，军师青衣秀士（唐士谦）、止观，师门方子敬（九州剑王，五虎之一，秦仲海与其兄之师）。以千万「饿鬼」（吃神力草致残的灾民）为兵。
- **武林 / 玄门**：昆仑山「剑神」[[卓凌昭]]（得神剑擒龙，后跳崖自尽）；华山宁不凡（天下第一，封剑归隐）、三达传人苏颖超；少林（天绝、灵定、灵真、灵智，灵定使修罗神功）；九华山张之越。江湖百花仙子胡媚儿、锦衣卫安道京等游走各方。
- **西域 / 外藩**：帖木儿汗国（银川公主和亲）、四王子莫儿罕；西辽后主帖木儿灭里；蒙古萨魔。五藩国使臣于红螺寺立储会汇聚。
- **潜在正统**：藏于神机洞的「驾崩」武英皇帝**朱炎**（vol12:1197 天绝僧点明、vol22:3809 原文，武英十五年八月与朱谨并列）、龙袍与正统玉玺；另一帝景泰帝**朱谨**（索引卷一亦见"景泰皇帝（朱谨）"，vol10:1245/vol14:3065 直呼御名）；靖江王潜龙朱阳（小泥鳅）；「皇后娘娘的儿子不姓朱」牵出的皇家秘辛（vol22:673/675 字条，待核）。

## 贯穿母题

- **[[忠而见诛 / 忠义被辜负]]**：楔子「我忠于朝廷，他们为何如此待我」到「我效命皇上，讲忠尽义，竟是这个下场吗」，全书贯穿。（相关页：[[忠义]]）
- **[[正邪之辨]]**：「玄门大派，禽兽不如」「少了侠的武会变成什么模样」「谁是坏人」，善恶界线在庙堂与江湖中反复模糊。
- **[[天命与人事之辨]]**：「戊辰岁终，龙皇动世」天机、「一代真龙」、「玺在人在，玺失人亡」、「天道无亲，以强者为亲」。（相关页：[[天命王道]]）
- **[[英雄的定义]]**：从「尽忠职守的捕快」到「侠即是夹，左仁右义」，再到「舍身换命方为大侠」。（相关页：[[英雄的定义]]）
- **[[乱世中正道何在]]**：「正道！不是夫子赏的，是用鲜血守卫的」，以及卢云水瀑十年悟出的「以圆应世」。（相关页：[[正邪之辨]]）
- **[[民本王道之辨]]**：「乱臣贼子不会无端生出」「万方有罪，罪在朕躬」「把人命化作算盘上的工时」。（相关页：[[仁政与民本]]）
- **[[乱世文章不值钱 / 才士的价值失落]]**：「玉皇若问人间事，乱世文章不值钱」，读书人在浊世被反复碾压。（相关页：[[气节与生死]]）
- **[[一代新人换旧人 / 传承更替]]**：「江山代有才人出」，卷末以「魁星战五关」新一代群像收束。
- **[[修罗道 / 以极恶手段求太平的悖论]]**：「欲救众生苦，须持修罗法」，[[杨肃观]]的政道伪善统御。（相关页：[[报应轮回]]）

## 从改编看（高光密度大的卷 → [[candidates]]）

单主角聚焦、冲突与情感转折密集、改编高光密度突出的卷次：

- **[[vol06 一代真龙]]**：[[伍定远]]绝对主角，神机洞四险四难、心栈映照人心、冥海跳湖破关成「一代真龙」，动作与悬念密度极高。
- **[[vol11 重建怒苍]]**：几乎[[秦仲海]]一人的沉沦与重生史，徒手登珠母朗玛峰「问天」、绝境重生扬刀立誓，情绪弧线完整强烈。
- **[[vol15 镇国铁卫]]**：政变前夕多主线交汇——秦仲海「一刀斩向婴儿、卢云以额挡刀」、开寨跪降一夜白头、江充赴死，戏剧张力顶点。
- **[[vol14 正统王朝]]**：修罗王真身揭晓、诈死取玺、嫁祸柳府、血洗柳门，全书最大反转卷。
- **[[vol20 保卫京城]]**：万福楼一夜血战、「天诀」压群雄夺神剑魔刀、诸秘辛集中揭破、百万饿鬼兵临城下，高潮会战与真相叠加。
- **[[vol05 西出阳关]]**：卢云与银川公主绝壁死守、共历生死情愫暗生又大义诀别，情感高光集中（情感线改编重点）。
- **[[第二十二卷 八王世子]]**：红螺寺多路汇聚、核心大秘密揭露、「万方有罪，罪在朕躬」诛心之问收束，群像与政变悬念密集。
