# 第五卷 西出阳关

## 一段话梗概
本卷讲述卢云与"火贪一刀"秦仲海奉柳昂天之命，护送银川公主西行帖木儿汗国和亲的全程。一行人先在途中降伏怒苍山残部(言二娘等)，卢云由此初窥怒苍山旧事(五虎上将的断头石虎)；及至天山，恰逢汗国四王子莫儿罕趁兄长喀喇嗤亲王迎亲之机举兵政变，公主陷于乱军。卢云独自救出公主，与她攀上绝壁死守数日，共历生死，情愫暗生，公主对其倾心，卢云却始终以臣礼自持、心系顾倩兮。最终可汗脱困平乱，公主为汗国父子说情、以"待人以诚"感化可汗，被册立为准皇后。临别，卢云一度决意带公主逃回中土，公主却选择成全大义、独留西域，二人在阳关道上黯然诀别。同时穿插秦仲海遇怒苍山旧将"煞金"石刚——石刚因见秦仲海背上"敢笑黄巢不丈夫"的飞虎刺青而临阵罢手，埋下秦仲海身世之谜。

## 关键事件（每条一句 + 章名）
- 卢云、秦仲海奉命护送银川公主西行和亲，途中与东厂副总管薛奴儿龃龉不断。(第一章 银川公主)
- 途经县城，怒苍山残部言二娘一伙行刺公主未遂；薛奴儿欲滥杀百姓，被卢云、秦仲海拦下。(第一章 银川公主)
- 秦仲海在怒苍山下降伏言二娘等残部，追上山顶救活自尽的言二娘，得知怒苍山旧事与"西凉小吕布"韩毅之名。(第二章 西出梁山第一人)
- 卢云破解"戊辰岁终，龙皇动世"谶语为"吾皇犹在神机洞中"；公主释放三名刺客，直言父皇失德。(第三章 昭君出塞)
- 卢云单骑折服汗国十万迎亲大军，展现天朝威仪；公主与粗鄙好色的喀喇嗤亲王达伯儿罕会面。(第四章 天朝国威)
- 四王子莫儿罕率黑甲军政变，卢云攀绳跳崖冲入乱军救出公主，二人攀上绝壁。(第四章 天朝国威)
- 秦仲海连斩乌力可罕、擒"象王"铁力罕，却败于汗国第一武勇"煞金"的诡异刀索。(第五章 西疆第一武勇)
- 卢云在悬崖上以血肉之躯抵御番僧围杀，屡次舍命护主，公主为其疗伤，情愫渐生。(第六章 忠义之心)
- 崖顶数日相守，卢云与公主看天山明月互诉身世；卢云道出顾倩兮之事，公主黯然。(第七章、第八章)
- 汗国大僧正罗摩什率众上崖劫驾，卢云连破陷阱，最终以身为垫脚石将公主抛过峡谷、自己坠崖。(第八章 明月出天山)
- 火山爆发的气流卷起卢云救他一命；秦仲海背上飞虎刺青令煞金石刚临阵罢手，埋下身世伏笔。(第九章 大难不死)
- 四王子欲火焚公主，卢云被投石机射入敌阵救下公主；煞金反戈擒住四王子。(第九章、第十章)
- 木里诧可汗率二十万大军脱困平乱，公主以"待人以诚"说情感化可汗；罗摩什行刺可汗被卢云救驾、自尽。(第十章 可汗大点兵)
- 公主被册立为准王妃/皇后；卢云决意带公主逃回中土，公主却成全大义、独留西域，阳关诀别。(第十一章 劝君更尽一杯酒)

## 高光 / 可改编点（指向候选段落）
- **崖顶明月对话**(第八章)：卢云吟"明月出天山，沧茫云海间"，公主吐露"我也只是个平凡姑娘"——单场景、双人、情绪极浓，全卷情感最高点。
- **阳关诀别**(第十一章)：卢云决意带公主走，公主含泪成全大义独留西域，深深一吻。极简场景、双人独白式。
- **煞金树下悲歌问天**(第七章)：石刚"天苍苍兮临下土，胡为不救万灵苦"独白，单人、天地苍茫，忠义孤臣的悲怆自白。
- **公主火刑遗言**(第十章)：公主临火不惧，遗言愿骨灰洒天山、息止干戈——单人独白、情绪强烈。
- **卢云舍身抛公主过崖**(第八章)：以命换命的悲壮牺牲，双人、动作与情感交织。

## 逐章梗概（每章 1~2 句，含章名）
- **第一章 银川公主**：卢云、秦仲海护送银川公主西行和亲启程。途中怒苍山残部言二娘行刺公主，薛奴儿欲滥杀百姓被拦，公主显仁厚、当众批评父皇失德。
- **第二章 西出梁山第一人**：一行经怒苍山，秦仲海降伏言二娘等残部，追至山顶救活自尽的言二娘，为她疗伤，得窥怒苍山"忠义堂"五虎上将断头石虎的旧事。因赶路需冒险出关，薛奴儿受激愿去玉门关调兵。
- **第三章 昭君出塞**：卢云破解谶语"吾皇犹在神机洞中"，天现峡谷异象。公主亲审并释放三名刺客(金毛龟等)，直言父皇纵容八虎、失了民心。
- **第四章 天朝国威**：卢云单骑喝退汗国十万迎亲大军，尽显天朝威仪；公主与粗俗好色的达伯儿罕会面。忽逢四王子黑甲军政变，卢云跳崖冲入乱军救出公主，二人攀上绝壁。
- **第五章 西疆第一武勇**：秦仲海连斩狂将乌力可罕、擒服"象王"铁力罕，威震敌营；却在汗国第一武勇"煞金"的诡异刀索(可分十二节)下落败，率军退往玉门关。
- **第六章 忠义之心**：卢云在悬崖上独抗番僧围杀，身中数刀仍死守护主。攀上崖顶后公主降尊为其疗伤、擦汗，二人情愫暗生，公主始知卢云乃落第书生、面贩出身。
- **第七章 天苍苍兮临下土**：卢云、公主于崖顶相守，共赏天山、互诉心事。另线秦仲海逃入树林遭煞金追杀，见煞金在一株大树("都督"墓)前悲歌问天，方知此人身怀千古奇冤。
- **第八章 明月出天山**：崖顶数日相处，二人渐去拘束、看明月互诉身世；罗摩什率众劫驾，卢云连破陷阱、以身为垫脚石将公主抛过峡谷，自己坠入深谷。
- **第九章 大难不死**：火山爆发的气流卷起卢云，救他一命；公主独行被罗摩什再次擒获。煞金因见秦仲海背上"敢笑黄巢不丈夫"飞虎刺青而临阵罢手，问及羊皮下落后飘然离去。
- **第十章 可汗大点兵**：四王子欲火焚公主，卢云被薛奴儿以投石机射入敌阵救下公主；煞金反戈擒住四王子。木里诧可汗率二十万大军脱困驾临，平定叛乱。
- **第十一章 劝君更尽一杯酒**：可汗审四王子、揭破安插死间之谋；公主以"待人以诚"感化可汗，被册立为准皇后。卢云一度决意带公主逃回中土，公主含泪成全大义独留西域，阳关道上黯然诀别。
