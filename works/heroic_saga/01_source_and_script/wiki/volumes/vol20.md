# 第二十卷 保卫京城

## 一段话梗概
正统十一年元宵深夜，怒苍烽火千里传讯，帖木儿灭里护送银川公主秘密入京，各方人马于京师暗中角力。朝廷以「霸州流民成蝗」为由深夜召集武林高手，宣称要追缉逃脱十二年的「向导」——怒王秦仲海；实则马人杰早已看破无人可用的困局。万福楼一夜血战，「镇国铁卫」倾巢而出，「大掌柜」现身以「天诀」统驭群雄内力，力压卢云、苏颖超、伍崇卿与秦仲海，独夺神剑魔刀。卢云追逐伍崇卿坠入地下水脉，得遇「善穆义勇人」——首领竟是万福楼台柱「琦小姐」，会同还俗的少林方丈灵智、烧毁面容的韦子壮、西域煞金灭里，逐一揭破十年秘辛：正统复辟、玉玺现世、天绝之死、柳昂天之死，一切幕后皆指向「大掌柜」杨肃观；银川回国实为扶景泰复出、以汗国百万兵马换取剿灭怒苍，而她也早已备好后手，请卢云刺杀杨肃观。天亮时分，卢云怀抱失而复得的阿秀走出枯井，京城四门紧闭——霸州百万饿鬼已兵临城下，伍定远拖着伤兵残部退回，振臂高呼「保卫京城」，怒苍大军直扑天子脚下。

## 本卷主线人物
- [[卢云]]——本卷绝对主角，出水瀑后重返京城，一夜追查十年真相，被众人推为「最后一卦」的刺客人选。
- [[杨肃观]]——即「大掌柜」，「镇国铁卫」最高首领、天绝关门弟子「灵吾玄志」，本卷终极幕后黑手。
- [[秦仲海]]——即「怒王」「铁脚大汉」，万福楼突袭大掌柜，率霸州百万饿鬼杀向北京。
- [[伍定远]]——「一代真龙」，正统军大都督，拖伤兵退回京城，高呼保卫京城；其身周被艳婷、巩志层层监控。
- [[苏颖超]]——三达传人，本卷追求「无上正圆」与仁剑，万福楼败于伍崇卿与大掌柜，最后被喂「松子糖」踏上新旅程。
- [[伍崇卿]]（龙影）——伍定远之子，背负业火魔刀的「镇国铁卫·龙影太子」，欲逼父亲突围。
- [[灵智]]（林先生）——还俗少林方丈，「善穆义勇人」核心，永定河射杀杨肃观的开枪人。
- [[帖木儿灭里]]（煞金）——西域帖木儿汗国大元帅，末代契丹人，护送银川公主入京。
- [[银川公主]]——回国扶景泰复出、以汗国兵马换剿怒苍，暗中布局刺杀杨肃观（本卷未正面登场）。
- [[韦子壮]]——柳门旧护卫，永定河大火烧毁面容，投身义勇人。
- [[金凌霜]]（剑寒）——镇国铁卫四当家，万福楼与伍崇卿激战，练成「剑芒」。
- [[马人杰]]——兵部尚书，硬骨头，深夜召集群雄追缉「向导」。
- [[吕应裳]]（若林）——华山九代之首，兵部戏份的引路人。

## 关键事件（每条一句 + 章名）
- 怒苍以「红白金青」四色灯讯千里传讯，潼关赵任勇兄弟破译出「去你妈的狗杂碎，少说两句不嫌吵」的欺敌废话（第一章 怒峰顶上）。
- 帖木儿灭里于杨无敌庙得知自己是末代契丹人，遇秦仲海大军压境，抱杨业神像跳入枯井躲藏（第一章 怒峰顶上）。
- 马人杰深夜以「蚱蜢变蝗虫」的比喻，揭露霸州流民聚为百万反军、勤王军已败退，召群雄追缉「向导」秦仲海（第二章 大后方 / 第三章 天堂有路你不走）。
- 郁丹枫（纯阳功传人）在万福楼外绳界与黑衣人（秦仲海）交手，杨肃观现身喝止（第三章 天堂有路你不走）。
- 苏颖超以「化圆为方·仁剑」考较伍崇卿，伍崇卿意在「勇剑斩天罡」欲夺三达剑谱（第四章 地狱无门你自来投）。
- 万福楼血战：屠凌心、修罗巨人、金凌霜相继登场，伍崇卿拔出业火魔刀（第四章 / 第五章 天诀）。
- 林先生向灭里以「蜂巢六道」讲解天诀，点出银川真正目的是「和局」与破解皇室「潜龙」诅咒（第五章 天诀）。
- 大掌柜以「天诀」同化六大高手内力压制全场，秦仲海破顶而降突袭，卢云屡次出手在三方间摇摆（第五章 天诀 / 第六章 修罗本相）。
- 大掌柜以「苦阴针」自疗，与老僧（灵智）道破秦仲海「烈火焚城」与自身「行尸走肉」之秘（第六章 修罗本相）。
- 卢云追伍崇卿坠入地下水脉，遇「善穆义勇人」，过「贪嗔痴」三关分别对上韦子壮（推手）、灭里（左手拳）、灵智（开门见山）（第七章 善穆义勇人）。
- 灵智揭露十年天机四卦、永定河刺杀杨肃观、玉玺现世、「反杨十大臣善穆义勇人」的由来（第八章 天机）。
- 首领「琦小姐」现身，逐一揭破镇国铁卫六大当家（艳婷/琼武川/巩志/金凌霜/灵真/罗摩什）与「客栈=天下过客」之义，请卢云计诱顾倩兮刺杀杨肃观；归还阿秀与云梦泽剑（第八章 天机 / 第九章 大赢家）。
- 破译胡正堂之疯，得知枯井藏活着的景泰皇帝（「龙袍鬼」「大赢家」）（第八章 天机 / 第九章 大赢家）。
- 卢云出井，京城四门紧闭，霸州百万饿鬼兵临城下，伍定远拖伤兵回京高呼「保卫京城」，怒苍大军直扑北京（第九章 大赢家）。

## 高光 / 可改编点（指向候选段落）
- 帖木儿灭里破庙独处、抱杨业神像跳井——末代契丹人身世独白，单人、情绪极强（第一章）。
- 苏颖超万福楼失一切、五楼纵身跳下、被大掌柜喂「松子糖」流最后一滴泪——「长大就是再没人见你哭」，凄美（第四、六章）。
- 卢云在地下水脉三关比武，「正十七·化圆为方」的仁者之武——武学哲思高光（第七章）。
- 卢云独坐陋巷抱阿秀，晨光中面对「刺杀杨肃观」的道德困境独白（第九章）。
- 结尾伍定远拖伤兵回城、振臂高呼「保卫京城」，怒苍饿鬼歌声压城——史诗级战争群像（第九章）。

## 逐章梗概（每章 1~2 句，含章名）
- **第一章 怒峰顶上**：怒苍以灯讯烽火千里传讯，潼关破译出一句欺敌废话；帖木儿灭里率白袍武士于杨无敌庙候命，发现自己是末代契丹人，遇秦仲海大军压境，抱神像跳枯井躲藏。
- **第二章 大后方**：京城大后方华山吕应裳一家的家常闹剧，北直隶总捕头深夜传召华山、崆峒、武当、少林等各派长老赴兵部；引出「立储案」与霸州异动的悬念。
- **第三章 天堂有路你不走**：武当纯阳功传人郁丹枫登场狂傲，兵部众高手内力较量；马人杰以「蚱蜢报仇」的比喻层层揭示霸州流民成军、勤王军败退，召群雄追缉戴斗笠的「向导」（秦仲海），万福楼外郁丹枫与黑衣人交手、杨肃观现身喝止。
- **第四章 地狱无门你自来投**：借伍崇卿引出「真龙之体」；万福楼上苏颖超以「化圆为方·仁剑」考较伍崇卿，伍崇卿欲夺三达剑谱练勇剑；哲尔丹、宋通明、屠凌心、修罗巨人相继登场，伍崇卿倒立运功、扎银针、亮龙掌，大战一触即发。
- **第五章 天诀**：以「蜂巢六道」阐释天诀心法；林先生向灭里揭示银川「和局」之志与皇室「潜龙」诅咒；万福楼大掌柜以天诀同化六大高手内力压制全场，秦仲海破顶突袭，三雄鼎立、神剑魔刀数度易手。
- **第六章 修罗本相**：金凌霜（剑寒/剑芒）与伍崇卿惨烈对决；大掌柜以修罗法相、六道轮回制服群雄，秦仲海坠楼、伍崇卿携魔刀逃走；事后大掌柜以「苦阴针」自疗，与灵智道破「烈火焚城」与自身「行尸走肉」之秘，并往红螺寺为银川安排。
- **第七章 善穆义勇人**：卢云追伍崇卿坠入地下水脉，遇「善穆义勇人」，过「贪嗔痴」三关——鬼面韦子壮（太极推手）、长发灭里（左手拳）、林先生灵智（开门见山），卢云以「正十七·仁剑」应对，三人真身逐一揭晓，卢云跪抱烧毁面容的韦子壮痛哭。
- **第八章 天机**：韦子壮、灵智向卢云揭破十年秘辛——天机四卦、永定河刺杀杨肃观、玉玺现世、正统复辟；破译胡正堂之疯，得知枯井囚着活着的景泰皇帝；亮出镇国铁卫「大鹏金翅鸟」与修罗王本相、六大当家名录，确认大掌柜即杨肃观「灵吾玄志」。
- **第九章 大赢家**：首领「琦小姐」现身请卢云计诱顾倩兮刺杀杨肃观，归还阿秀与云梦泽剑；卢云出井抱两童，京城四门紧闭，伍定远拖伤兵回京高呼「保卫京城」，霸州百万饿鬼唱着怒歌兵临城下，怒苍大军直扑北京。
