# 秦仲海 · 残废绝境期

**阶段范围**：vol10›第五章 — vol11›第七章

## 一句话形象
柳门火贪一刀被江充刖去左腿、穿透琵琶骨、额刺"罪"字，从堂堂虎林军统领一夜坠为拄杖跛行的乞儿废人；在黄河怒涛、蒋门神地盘和珠母朗玛峰顶依次求死不得，最后徒手登顶"问天"、扬刀立誓重建怒苍。

## 性格与核心驱动
不认命——身为秦霸先遗孤又被冠以"罪"名，绝境之下要向天讨一个说法：宁做一日猛虎，不做三十年残废。

## 关键抉择时刻 ★改视频着力点
- 示警刘敬事败反遭江充擒获，遭刖足、穿琵琶骨、额上刺'罪'（vol10›第六章 纵使相逢应不识）
- 雪地追随刘敬中毒身亡，认父痛哭，树上刻'忠义孤臣枉痴心'七字（vol10›第五章 忠义孤臣枉痴心）
- 被卢云伍定远焦尸掉包偷梁换柱救出，废人之身强撑起立，独自策马遁走不愿连累众人（vol10›第七章 兄弟）
- 夜半独自持刀却握不住、投黄河自尽被救起，立志'领十万雄师杀回中原'（vol11›第四章 三十功名尘与土）
- 徒手登珠母朗玛峰问天，跳崖劈出'烈火焚城'一刀、六经八脉贯通、扬刀立誓重建怒苍（vol11›第七章 我自横刀向天笑）

| 下装/腰带 | 左腿齐膝而断，右侧裤管空垂或束起；右脚赤足或草鞋（vol11›'赤着一只左脚'） |
| 外披 | 雪地追刘敬时披斗篷/军氅；乞街与登山阶段是破絮短袄，登珠母朗玛前方子敬处换厚裘皮袄（登顶时被风雪撕破） |
| 足履 | 单脚草鞋/赤足，靠一根粗木拐杖支撑（vol11 拐杖是核心道具，投河时'拐杖被冲得不见踪影'） |
| 兵器/持物 | 钢刀（火贪一刀，标志兵器）——但琵琶骨被穿后握不住刀，一度让钢刀落地；直到峰顶跳崖一刀劈山，武功暴增才真正复握 |
| 标志物 ★ | 背上的猛虎/飞虎刺青（西字虎，怒苍身世的核心视觉符号，全身赤裸时最显眼）+ 额上'罪'字 + 单腿拐杖，三件套构成本阶段最强辨识度 |
| 主色 ★ | 血赭+雪白+破布灰（额上罪字与琵琶骨渗血的暗红/双肩血染衣衫，配对黄河冰面、珠母朗玛雪山的惨白，与身上破粗布的土灰）——推断色，需与四主角对比后定 |
| 剪影轮廓 ★ | 高大男子拄拐单腿跛立，前额乱发覆'罪'字、背影露出巨大猛虎刺青——从任何角度看都是'一头戴罪的独腿病虎' |

> ★ 号项是四主角需要**互不重叠**的辨识锚点。抽卡前先与其他阶段卡横向比一遍。
